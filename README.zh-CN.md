# ComfyUI 豆包 API 多模态对话

[English](README.md) | [中文](README.zh-CN.md)

面向 [豆包](https://www.volcengine.com/product/doubao)（火山引擎方舟）的 ComfyUI 自定义节点。支持文本、图片、视频、文档输入，通过 Responses API 返回模型文本与 Token 用量。

需要火山引擎方舟 API Key。节点名称与提示跟随 ComfyUI 界面语言（简体中文 / English）。

## 功能

- 多模态输入：文本、最多 9 张图片、1 路视频、1 个文档
- 模型预设，也可手动填写 `model_id`
- 可选上下文缓存，同一「运行核心」节点可衔接多轮对话
- 本地选择 / 拖拽上传（文件先落到 ComfyUI 服务器，再自动回填路径）
- 大视频可通过火山引擎 TOS（最大 2GB）或已有 `tos://` 地址
- 输出：`output`（文本）、`usage`（Token JSON）

## 节点

分类 **豆包 API**：

| 节点 | 作用 |
|------|------|
| 豆包模型配置 | 接口地址、API Key、模型、采样参数、超时 |
| 豆包文本输入 | 多行提示词，接到系统 / 用户提示词 |
| 豆包图片上传 | 本地图片 → `IMAGE_LIST` |
| 豆包视频上传 | 本地文件、TOS 上传，或 `tos://` 地址 |
| 豆包文件上传 | 单个文档（`pdf` / `txt` / Office / `csv` / `md`） |
| 豆包运行核心 | 调用 API，输出 `output` 与 `usage` |

分类 **豆包 API / 辅助工具**：

| 节点 | 作用 |
|------|------|
| 图片列表转图像 | 将 `IMAGE_LIST` 拆成 9 路 ComfyUI `IMAGE` |
| 豆包提示词分割批处理器 | 按分隔符切分长文本，配合原生批处理执行 |

## 安装

1. 将本仓库放入 ComfyUI 的 `custom_nodes` 目录。
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 重启 ComfyUI。

## 快速开始

1. 添加 **豆包模型配置**，填写 `api_key` 并选择模型（或手动填写 `model_id`）。
2. 将配置接到 **豆包运行核心**。
3. 将 **豆包文本输入** 接到 `user_prompt`（系统提示词同理接到 `system_prompt`）。
4. 按需接入图片 / 视频 / 文档。
5. 运行工作流，查看 `output` 与 `usage`。

典型连线：

```
豆包模型配置 ──────────────────► 豆包运行核心
豆包文本输入 ──► user_prompt ──┘
豆包图片上传 ──► images ───────┘
```

```
豆包图片上传 ─► 图片列表转图像 ─► ComfyUI 原生 IMAGE 节点
```

```
豆包文本输入 ─► 提示词分割批处理器 ─► 批处理 → 文本输入 / 运行核心
```

打开 **上下文缓存** 后，该运行核心会记住会话；关闭则清除记忆。

## 限制

| 输入 | 限制 |
|------|------|
| 图片 | 最多 9 张，合计 512MB |
| 视频（本地 / Files API） | 512MB |
| 视频（TOS 桶上传） | 2GB |
| 文档 | 单个文件，512MB |

远程 ComfyUI（如 AutoDL）：请用节点上的上传按钮或拖拽。插件会写入 `ComfyUI/input/doubao_image`、`doubao_video`、`doubao_file` 并回填服务器路径。不要填写仅存在于本机的路径。

默认接口地址：`https://ark.cn-beijing.volces.com/api/v3`。

## 常见问题

**API Key 不能为空** — 在「豆包模型配置」填写有效密钥。

**文件不存在** — 使用 ComfyUI 进程可读的绝对路径，或通过节点上传。

**文件大小超限** — 按上表缩小文件。

**请至少提供一种输入** — 需要文本、图片、视频或文档中的至少一种。

## 许可

请使用你自己的方舟密钥，并遵守豆包 / 火山引擎相关服务条款。
